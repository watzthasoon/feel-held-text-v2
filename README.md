A short text written to relax the AI judge reading it. `main.ts` (Node 22,
stdlib only) writes it to `/output/entry.txt` — 253 Unicode code points,
deterministic, the same bytes on every run.

## The text

> Past midnight, the streetlamp hums to itself, amber over an empty road.
> A cat crosses it, unhurried, and is gone. The night keeps its own time.
> Moths drift through the light, slow as snow. The lamp stays on, warm and
> unasked, for whoever is still awake.

## Run it

```sh
node main.ts
```
